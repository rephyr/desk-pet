# A2 Gear: build plan

Gear = upgrades bought with xp, on an "upgrades" page inside the adventures tab
(adventures | upgrades, same switch as machine | upgrades). The 8 upgrades and numbers come from
docs/dev-plan.md A2. Look: gear.html's crayon path of stickers, with effects shown as numbers.

## Files

New
- `data/gear.json`: the 8 upgrades in path order, plus the base values they change.
- `scripts/adventure/gear.gd`: `class_name Gear`, pure static rules (catalog + levels in, numbers out).
- `scripts/ui/gear_view.gd`: `GearView`, the upgrades page (path + detail card).
- `tests/flows/gear.flow`.

Changed
- `scripts/core/catalog.gd`: loads gear.json into `catalog.gear`.
- `scripts/adventure/run_state.gd`: `gear` (levels packed when the trip set off) and `saves_used`
  (first-aid leaf saves used this trip). Both saved with the run, default `{}` / `0`.
- `scripts/adventure/adventure_runner.gd`: boots in `gap()`/`duration()`, charm in
  `success_chance()`, harness + leaf in `play()`, sharper eyes in `_finish_treat()`,
  `estimate_return()` takes gear too.
- `scripts/adventure/party.gd`: `hurt()` can save pets (turns a loss into "stays hurt").
- `scripts/adventure/pet_voice.gd`: `hint()`/`spotted()` take the charm's luck, so the pet's words
  shift by themselves (no odds shown).
- `scripts/game_state.gd`: gear levels, xp spending, packing gear on each trip, tote in
  `_boost_trip_loot`, pouch in `toss_treat` (TREAT_EVERY / TREAT_ZOOM become functions), sticky
  paws in `trail_pickup`. Save v22.
- `scripts/ui/trail_view.gd`: STREAK_MAX becomes the run's gear value; sharper eyes raise the part
  weight (only once feature:parts is open).
- `scripts/ui/adventures_tab.gd`: becomes a VBox: the switch bar on top, then the existing
  map/away page or GearView.
- `scripts/ui/ui_theme.gd`: 8 gear icons (boots, tote, paws, leaf, charm from gear.html; pouch,
  eyes, harness new).
- `data/voice.json`: pet lines for the page (open, pick, bought, not enough xp, all done).
- `scripts/dev/dev_driver.gd`: steps `xp <n>` and `gear <id> [levels]`.
- `tests/test_core.gd`: `_test_gear`.
- Docs: CLAUDE.md (session notes; drop the "luck on risky trip choices" note from the toys line,
  gear owns it now), docs/dev-plan.md (A2 built), docs/design.md, docs/architecture.md.

## Data shape (data/gear.json)

```json
{
  "base": { "treat_every": 15, "treat_zoom": 8, "streak_max": 1.5, "part_x": 1 },
  "leaf_text": "the first-aid leaf helped!",
  "gear": [
    { "id": "boots", "name": "comfy boots", "icon": "gear_boots", "color": "pink",
      "does": "pets walk faster on trips",
      "xp": 30, "grow": 1.6, "max": 5, "each": { "walk": 0.08 },
      "show": "trips {walk%}% shorter" },
    { "id": "tote", "name": "a tote bag", "xp": 25, "max": 4, "each": { "coins": 0.15 },
      "show": "+{coins%}% trip coins" },
    { "id": "pouch", "name": "a treat pouch", "after": "boots", "xp": 40, "max": 3,
      "each": { "treat_every": -2, "treat_zoom": 1 },
      "show": "a treat every {treat_every} s, zoom {treat_zoom} s" },
    { "id": "paws", "name": "sticky paws", "after": "tote", "xp": 60, "max": 3,
      "each": { "pickups": 0.2, "streak_max": 0.25 },
      "show": "trail finds +{pickups%}%, streaks up to x{streak_max}" },
    { "id": "eyes", "name": "sharper eyes", "after": "pouch", "xp": 50, "max": 3,
      "each": { "bits": 0.15, "part_x": 0.5 },
      "show": "+{bits%}% bits", "show_parts": "+{bits%}% bits, trail parts x{part_x}" },
    { "id": "charm", "name": "a lucky charm", "after": "paws", "needs": "location:meadow",
      "xp": 80, "max": 3, "each": { "luck": 0.04 }, "show": "+{luck%}% luck when it's risky" },
    { "id": "leaf", "name": "a first-aid leaf", "after": "eyes", "needs": "location:meadow",
      "xp": 60, "max": 3, "each": { "saves": 1, "save_share": 0.1 },
      "show": "{saves} saves a trip, parties {save_share%}%" },
    { "id": "harness", "name": "a comfy harness", "after": "leaf", "needs": "feature:parties_5",
      "xp": 120, "max": 3, "each": { "harm": 0.1 }, "show": "{harm%}% fewer hurt or lost" }
  ]
}
```
(Every entry has icon, color, does, grow 1.6; shortened above.)

- Price of the next level = `xp * grow^level`. These are starting numbers in the 25-120 range from
  the plan; the A1 sim can tune them.
- A value = `base + each * level`. `{key}` in "show" prints the number, `{key%}` prints it x100.
- The pouch at lv 1/2/3: a treat every 13/11/9 s, zoom 9/10/11 s. The trail's part weight is
  4 x part_x (4, then 6/8/10).

## Rules (Gear, pure)

- `value(catalog, levels, key)`, `price(catalog, id, level)`, `words(catalog, id, level, parts_on)`.
- `shown(catalog, levels, is_open)`: path order. A sticker shows once its "after" has lv 1 or
  more and its "needs" (an unlock id, checked with GameState.is_open) is open. Boots and tote show
  from the start. Stickers that don't show yet aren't drawn at all (hidden until earned).
- `for_trip(catalog, levels, location)`: the levels to pack on a trip; `{}` for dungeons
  (location type "dungeon"). Gear never works in dungeons.
- Reach: every trip goes through `GameState.send_on_adventure` (yours, your pet's auto parties,
  workers' parties), so they all get the packed gear. Offline catch-up uses the run's packed gear.
- The effects:
  - boots: `gap() x (1 - walk)`, applied after the speed clamp.
  - tote: trip coins x (1 + coins) in `_boost_trip_loot` (this includes coins picked up on the trail).
  - pouch: `treat_every(run)`, `treat_zoom(run)`.
  - paws: trail coins and xp x (1 + pickups); streak cap = streak_max.
  - eyes: in `_finish_treat`, each bit found rolls again for +1 at `bits` chance
    (`Rewards.count`). Trail part weight x part_x once feature:parts is open.
  - charm: + luck on options whose failure hurts, injures or loses, before the MAX_CHANCE 0.95 cap.
  - leaf: a pet that a `hurt` outcome would lose stays hurt instead. A solo trip gets `saves` of
    these a trip (`run.saves_used` counts them). A party of 2 or more saves each such pet at
    `save_share` chance. When it saves someone, `leaf_text` goes on that event's line.
  - harness: the counts from `hurt`, `injured` and `lost` outcomes x (1 - harm).

## GameState

- `var gear := {}` (id -> level). Save field `"gear"`, SAVE_VERSION 21 -> 22. No migration step
  needed: old saves load with `{}`. Loading clamps levels to 0..max and drops unknown ids.
- `signal gear_changed`.
- `gear_level(id)`, `gear_block(id)` ("" / "max" / "hidden"), `gear_price(id)`,
  `buy_gear(id) -> bool` (spends xp, saves, emits gear_changed + changed),
  `set_gear_level(id, n)` (dev), `shown_gear()`, `gear_page_open()` (xp > 0 or any gear bought),
  `trip_gear(location_id)` (for the picker's time/odds preview).
- `send_on_adventure` sets `run.gear = Gear.for_trip(...)`.

```

|                                     )    | |   pets walk faster   |
|  (harness)~~(leaf)~~~~(charm)~~~~(eyes)  | |   o o o . .          |
|                                          | |   now   trips 24%... |
|  crayon road: dashed, walked part solid  | |   next  trips 32%... |
+------------------------------------------+ |   [ get it  56 xp ]  |
                                             |   you have 72 xp     |
                                             +----------------------+
```
- Left: a paper panel with the crayon road (Crayon), 4 stickers a row, snaking. It scrolls if it
  ever needs to. A sticker: a tilted icon square, the name, level pips, the effect as a number,
  the price in xp. Picked = pink stitching; max = gold border + star; can't afford = faded price.
- Right, a 230 px card: big icon, name, "does" line, pips, now / next rows (next in mint), a buy
  button ("get it" + price; "not enough xp yet" disabled; "all done! ♡" at max), "you have N xp".
- Tap a sticker to pick it, tap it again (or the button) to buy. Buying: a squash + sparkles
  and a happy pet line.
- The switch bar is hidden until `gear_page_open()`. On the adventures page the map, place card,
  trail and "away" column are the same as now, just a bar's height shorter. Checked with
  `expect fits` on both pages, with a place card open.
- Not built from the mockup: the sealed "further down the path" stops, the "something jingly…
  almost there" teaser, and the asleep page (all break "hidden until earned"). The "new!" tag is
  skipped too: it would need its own save field.

## Tests (tests/test_core.gd, `_test_gear`)

- Data: 8 upgrades, each has name/icon/xp/grow/max/each/show, "after" points at an earlier one,
  "needs" is a known unlock/location id, every `{key}` in "show" is a key it changes or a base.
- Prices: lv 0 = xp, lv 1 = round(xp x 1.6).
- Values: boots lv 5 walk 0.40; pouch lv 3 = 9 s / 11 s; paws lv 3 streak cap 2.25; eyes lv 3 part
  weight x2.5.
- `shown`: nothing bought = boots + tote; boots lv 1 adds the pouch; the charm waits for the meadow;
  the harness for parties_5.
- `for_trip` on a dungeon (the well) is `{}`.
- Runner: boots lv 5 gap = 0.6 x the plain gap; charm lv 3 adds 0.12 to a risky option, capped at
  0.95, and nothing to a safe one; harness lowers meadow losses over many seeded runs; a hurt solo
  pet hit again with the leaf stays (saves_used 1), a second hit without saves left is lost;
  sharper eyes lv 3 bring more bits over many seeded finishes.
- RunState round trip keeps `gear` and `saves_used`.
- Also run: `godot --headless -s tools/balance.gd` (no gear there, numbers must not change), all
  existing flows that touch adventures (postcard, party, tutorial, fits).
