# B3 plan: automation layer 2, the whistle (look A: the to-do list)

Sources: dev-plan B3, picks.md (B3 lines), mockup automation-layers.html look A.

## What it does
- A **tiny whistle** turns up at **the old well** once you have **N workers** (all jobs added up,
  N = 30 placeholder). Finding it opens `feature:whistle`: the automation switch grows a third
  button, **whistle** (your pet | workers | whistle).
- Managing with the whistle **is your pet's one job** (task `"whistle"`, pill: "<pet> is
  managing"). No teach price: the find is enough (it's marked taught when it opens).
- While your pet manages, every `check_seconds` it checks on everyone. Per job (machines, tables,
  parties) two ticks: **haul them home** (parties: **start new ones**) and **keep them full**.
  - haul: buys spots with coins, never dipping under **set aside**; the cheapest next spot among
    ticked jobs first; `1 + wagon` spots per check; only while some are **out there**.
  - fill: puts resting pets on empty machines/tables, gives empty parties a leader (best workers
    first, as `put_workers`). A new party goes to an open place that has none yet.
- **Lore / cap:** machines and tables come from places you've taken: each open map page adds how
  many exist (`spot.exist` per page). Parties: one per open place (`spot.per_place`). The cap
  holds for buying by hand too (the +1 button is simply gone at the cap); old saves keep spots
  already bought past it ("out there" shows 0).
- **Spot prices flatten:** past `flat_at` spots each one grows by `grow_late` instead of `grow`,
  so thousands are reachable.
- **Offline:** like the workers: checks keep happening for the stool's away hours
  (`Automation.away_seconds`), after that time's income is paid.

## Data
- `data/automation.json`
  - each job's `spot` gains `flat_at`, `grow_late`, and `exist` { page id: count }
    (machine { backyard 60, beyond 600 }, boxes { backyard 20, beyond 200 }) or, for adventures,
    `per_place: 1`.
  - new top-level `whistle`: { name "the whistle", icon "whistle", color "cyan",
    check_seconds 10, keep_steps [0, 10k, 50k, 250k, 1M, 5M, 25M, 100M, 1B, 10B], keep 250000,
    tools: [ pencil "a sharper pencil" (each check_speed 0.1), wagon "a bigger wagon"
    (each haul 1, max 9) ] }. Automation.job("whistle") returns it, all_tools includes its tools
    (job "whistle"), so tool buying/levels reuse the existing code.
- `data/unlocks.json`: finds + `{ id: "whistle", name: "a tiny whistle" }`; unlock `whistle`
  opens `feature:whistle`, earn { find: whistle, open: tab:automation }, popup
  "new: the whistle!" (go automation), announce "tweet! everyone, line up!".
- `data/adventures.json`: event `well_whistle` (find whistle, auto, **`after_workers: 30`**),
  added to the well's events. New event key `after_workers` documented in the _note.
- `data/voice.json`: automation_whistle, automation_do_whistle, automation_stop_whistle.
- UiTheme doodles: whistle, pencil, wagon.

## Code
- `scripts/idle/jobs.gd`: `tool_cost` gets the flat_at/grow_late tail, closed form (geometric
  sums, no per-spot loop).
- `scripts/idle/automation.gd` (pure rules): `exist(catalog, id, pages, places)`,
  `out_there(...)`, `whistle_fresh()`, `check_seconds(catalog, state)` (pencil),
  `haul_size` (wagon), `checks(catalog, state, seconds) -> int` (keeps `whistle.wait`).
- `scripts/adventure/adventure_runner.gd`: `start`/`pick_events` take `workers := 0`; events with
  `after_workers` wait for it.
- `scripts/game_state.gd`: `spot_room(id)`, spot_plan/buy_spots respect the cap and use a binary
  search for "as many as you can afford"; `set_whistle_tick(job, key, on)`,
  `step_whistle_keep(d)`; `_whistle_checks(n)` (quiet haul + fill, one save at the end), called
  from `_work_for_automation` when task == whistle (live and offline); unlocking
  `feature:whistle` marks it taught; `whistle_since` (not saved: hauled per job, pets put to
  work, reset when you leave the whistle page).
- `scripts/ui/automation_tab.gd`: segmented switch rebuilt with 2 or 3 buttons; `_page` 2 =
  **WhistlePage**: a clipboard panel (clip on top, paper inside) with "<pet>'s list" and a row
  per job taught to the others: icon + "machines" + "N working" + a tiny `ErrandsTab.Crowd`,
  "212 / home, 28 out there" (parties: "9 / of 11 places"), two tick boxes; under it "N pets
  resting" + crowd. Side card: "the whistle", your pet box ("<pet> is here ♡ / managing / take it
  off" or "nobody here / move it here"), "set aside  − 250k +", "upgrades" + two ToolRows, a
  "since you looked" foot only when something happened. Opens on the whistle page right after
  the unlock. Workers page: +1 button gone at the cap.
- `scripts/dev/dev_driver.gd`: `manage <n>` (the whistle checks n times now), `workers <job> <n>`
  (spots + pets on them, for free) if the existing steps get too long.

click "show me", expect text "haul them home", expect text "keep them full", expect fits, shot
whistle_page, click "move it here", expect text "managing", `manage 3`, expect text "since you
looked*", shot whistle_managing, untick one, expect fits, then spots machine 2000 + pets 3000 +
manage 1, expect fits, shot whistle_crowd; workers page at the cap: expect no-text "+1 machine*",
shot workers_cap. Also re-run `workers`, `automation`, `fits`.
