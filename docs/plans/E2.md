# E2 next door: build plan (look A, the street)

From docs/picks.md (E2 in "Brainstorm 2 picks" and "Look picks, round 2") and
design/mockups/screens/next-door.html look A.

## Data

**data/unlocks.json**
- pages: `{ "id": "next_door", "name": "next door", "paper": "night", "layout": "street" }`
  (the id the midnight box already uses in boxes.json). Backyard page gets `"ours_after": 40`
  (visits before a backyard place turns ours; placeholder).
- unlock entry `next_door`: opens `page:next_door`, show hidden, `"earn": { "called": true }`
  (a new earn key: never earned by check_unlocks, only by code calling the hook), announce +
  popup ("new: next door!", a plain line, go adventures).

**data/adventures.json**
- top-level `"ours": { "opens_with": "next_door", "danger": 0.5, "loot": 1.2,
  "say_dark": "shh... {house} is going to bed.", "say_ours": "look! i coloured {place} in!" }`
  (places only turn ours once next door is open).
- 6 locations, `"page": "next_door"`, `"box": "midnight"`, new ids so they don't clash with the
  backyard's garden/pond: `their_gate`, `their_path`, `greenhouse`, `their_pond`, `porch`, `doghouse`.
  New fields: `"lights": 3/4/5/5/6/8`, `"ours_at_start": true` (gate, path), `"risky": true`
  (doghouse). `map`: `x` = column in the street (pond 0, greenhouse 1, path 2, porch 3,
  doghouse 4), `y` 0 = a garden, 1 = in our fence (the gate); `trace` = the locals' trace doodle
  (slipper, can, cup, paper, bowl). max_party 20/30/30/50/50/100, minutes 8/12/12/20/20/30,
  loot ~8..20 (more than beyond), doghouse high danger + difficulty. All placeholders.
- gate and path `start: true`; greenhouse spotted from the gate, pond and porch from the path,
  the doghouse from the porch (`leads_to`, like the backyard).
- ~16 new night-garden events (moths, snail, sprinkler, tomatoes, the lamp, a frog, the porch's
  rusty capsule machine blinking, the big blanket...). The locals' ones get `"local": true`
  (a slipper, a watering can, a teacup, yesterday's paper, a big bowl, the dog's blanket) and stop
  at an ours place. Each place keeps at least `draws` non-local events. The porch machine is only
  an event here (the midnight globe is A5).

## Save (v23 -> v24)

- New field `"visits": { location id: n }` (trips welcomed back per place).
- Migration v<24: every place in `visited` starts at 1. RunState saves `"ours"` (default false).
- Ours is never stored: `visits >= lights`, or `ours_at_start`, or backyard `visits >= ours_after`,
  and always only while `opens_with`'s page is open.

## Code

- **GameState**
  - `open_page(page_id)`: THE hook for C2. Unlocks `page:<id>`, fires that page's unlocks.json
    entry (popup, announce, milestone) through the same code as check_unlocks (factored into
    `_open_entry`), emits new signal `page_opened(page_id)`. `_earned` returns false for `called`.
  - `visits`, `lights_left(id)`, `is_ours(id)`, `add_visits(id, n)`: collect_run calls
    `add_visits(run.location_id, 1)`. On turning ours: `say_ours` announcement and
    `just_ours = id` (not saved, the map animates it once). A hand-sent next door trip also says
    `say_dark` when a light goes out.
  - send_on_adventure passes `is_ours(id)` into AdventureRunner.start.
- **AdventureRunner / RunState**: `RunState.ours`; `start(..., ours)`; `pick_events` skips
  `local` events when ours; new `place(state, catalog)` = the location with danger x0.5 and
  loot x1.2 when ours, used where the runner now calls `catalog.location(state.location_id)`
  (resolve, play, finish treat, run_gap). `estimate_return` takes `ours` for the card.
- **Catalog**: `page_info(id)`, `ours` (the adventures.json block).
- **PetLook.main_color(pet)**: the palette's body colour (the pet's own crayon colour).
- **MapView**: page `paper: night` darkens the paper (PAPER toward DEEP, from theme roles).
  Page `layout: street` hands drawing, hit-testing and walking pets to a new
  **scripts/ui/street_page.gd** (StreetPage, static helpers drawing into the MapView):
  stars + moon, a row of house backs across the top (one per garden column, roof peaks, a chimney
  on every other), windows = lights (lit ones first, 2 rows), picket fences between gardens, our
  fence along the bottom with their gate in it, the path from the gate along the bottom with a
  spur up into each garden, the garden's doodle + name + note, the locals' trace when not ours.
  Ours: the garden scribbled in (crayon zigzags) in the active pet's colour, doodle and name in it,
  a flag on the roof, a little flower in place of the trace. Hit area = the garden's column.
  Gardens not found yet: just their house with lit windows (no doodle, no name, no ? cloud);
  spotted: faded doodle + "X saw this! tap to go!" as today. Pets walk in through the gate, along
  the path, up the spur.
  Backyard (free map): an ours place gets the scribble fill + pet-colour doodle and name + a small
  flag by the doodle.
- **Crayon**: new doodles gate, greenhouse, porch, doghouse, flag, window; traces slipper, can,
  cup, paper, bowl.
- **AdventuresTab** place card: a row of little windows under the note (lit = visits left) while
  not ours; facts get a "risky" tag (doghouse, not ours) and a coin tag "x1.2" when ours. On the
  street the card sticks top-left when the garden is in the right half (so it doesn't cover it).
- **BoxShop**: nothing new; the midnight tier appears because `page_open("next_door")` is true.

## Dev steps (DevDriver)

- `open <page>`: calls GameState.open_page (popup and all, as C2 will).
- `visit <place> [n]`: n visits through add_visits (lights go out, ours, announcements).
- `expect ours <place>` / `expect lights <place> <n>`.

## Flow: tests/flows/next_door.flow

from rich, view full; boxes tab: no "midnight box"; `open next_door`, wait popup, expect

## Tests (tests/test_core.gd)

- data: every next_door place has lights, map column, midnight box; each place keeps >= draws
  non-local events; local events exist; page next_door exists and nothing but `called` opens it.
- hook: open_page opens the page, fires the popup entry once, the midnight tier appears in
  open_tiers; check_unlocks never opens next door by itself.
- visits: collect_run counts one per trip; lights_left goes down; ours at lights; gate/path ours
  from the start; backyard ours only after ours_after AND with next door open; nothing ours
  while next door is closed.
- runner: ours pick_events never has local events; place() halves danger, x1.2 loot; RunState
  ours round-trips.
- save: visits round-trip; a v23 save migrates (visited -> 1 visit each), version = 24.
- balance.gd still runs with the new places.
