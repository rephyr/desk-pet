# F1/F2 plan: the plushie machine (look A, the cabinet) + buttons

From dev-plan F1/F2, picks.md (F1 lines, Details, Look picks round 2, Brainstorm 3) and
design/mockups/screens/sacrifice-reels.html look A. Placeholder numbers from the mockup, all in data.

## Rules (pure class `Plushie`, scripts/machine/plushie.gd)

- **Keeper:** any card pet you own except busy ones (away, pinned). Order for ‹ ›: active pet, pets
  with buttons, favourites, other cards (best rarity first). Swap only when nothing is held and no
  reel is rolling. The keeper is never harmed.
- **Hopper:** + on a rarity row takes one resting herd pet of that shelf (normal first, then
  shiny; off a job only if none rest, like adventures). "card pets" opens a small picker of resting
  cards (never the active pet, favourites or pets with buttons). A pet leaves the collection when it
  goes into the hopper (`collection.remove`, so it adds a night-sky star, nothing explained). There's
  no take-back. The hopper keeps small pet dicts (max `hopper_max`).
- **A fed pet:** the best one in the hopper hops in. Spins = rarity (1-6), nudges added to the pool
  = finish (normal 0, shiny 1, holo 2, ghost 3, glitch 4, prismatic 5), traits tilt the reels
  (lucky: crack -3, curious: button +2, greedy: wisps x1.5, zoomy: +1 spin; others nothing).
- **5 reels**, one per slot. Odds per reel come from that part's button count: button
  34/26/18/11/5 %, crack 8/11/15/19/24 %, blank = the rest (a full part shows "full!", doesn't spin).
- **Spin:** first every reel holding buttons that isn't on HOLD banks by itself. Then each live reel
  lands: button = held +1 (+2 if it was on hold and already held one), crack = held back to 0, blank
  = held stays. Held is capped at 5 minus the part's buttons.
- **Bank** a reel: its held buttons are sewn on, the reel stops for this pet. **Hold:** at most
  `hold limit` reels (starts at 2). **Nudge** (from the pool): a reel that just landed shifts down
  one (the cell above becomes the middle) and lands again from before.
- **Spins run out:** the "next!" button banks everything still held, the next pet hops in. Empty
  hopper: everything held is banked, "all done".
- **Misses puff wisps:** blank or crack = puff[fed rarity] (1/4/12/40/300/10000) x2 on a crack x
  perfection (1 + 0.1 x the keeper's buttons, placeholder).
- **Wild 6th reel** (bought with wisps for one fed pet): its part is picked with ‹ › on its head
  (default: the part with fewest buttons). Rolls with that part's odds; a button sews on straight
  away (no bank/hold on the wild reel); a miss puffs only.
- **Wisps buy:** nudges (60, x1.3 each), a hold slot (400, x2.5 each), the wild reel for this pet
  (250 x the fed rarity step, placeholder).
- A failed try costs only the fed pets and held buttons. Pets never automate it yet.

## Buttons on pets

- `Pet.buttons`: slot -> 1..5 (saved only when not empty). `Collection.always_card`: a pet with
  buttons is always a card.
- Knacks: a part's knack size x (1 + `knack_per_button` 0.5 x buttons) (5 buttons = x3.5). Done in
  `Knacks.of / sum_in / parts` (the counting table stays per part; buttons read off the pet).
- Grafting: buttons stay on the part. Sewing over a part with buttons puts it back in the bag as
  `slot:id@n`; sewing an `@n` part on sets that slot's buttons. `Grafting.split_key(key)` ->
  [slot, id, buttons]; inventory_tab reads keys through it and shows the tile's buttons. Same fail
  chance as today (question below).
- KnackBadge draws up to 5 tiny pink buttons round its rim; the details card's number already
  includes them.

## Wisps (the darker currency)

- `GameState.wisps` (int, saved top level) + `GameState.grant_wisps(n)`, and `grant()` takes
  `"wisps": n` (the dungeon lane's lanterns should call the same; merge unifies).
- Colour key `wisp` (candy floss coral) in all 5 themes (`UiTheme.WISP`), doodle icon `wisp` (the
  mockup's fluff puff). Shown only on the plushie machine's side card (look A).

## Opening (one hook)

- data/unlocks.json: `{ "id": "plushie", "opens": ["feature:plushie"], "show": "hidden",
  "earn": { "find": "plushie_machine" }, "button_gift": 1, "announce", "popup" (go: inventory) }`,
  finds + `plushie_machine` "a working plushie machine". E3's last room only has to
  `grant({"find:plushie_machine": 1})`. `check_unlocks` sees `button_gift` and sews that many free
  buttons on the active pet (on the slot of its best knack, else body). Nothing else gives the find.
- Workbench: `your pet | toys | plushie machine`, the third button hidden until `feature:plushie`.

```
                                            |  holds oo [+ 400]  |
                                            |  wild [+ 250]      |
                                            +--------------------+
```
Drawn in code like MachineStage (pink cabinet, lilac hopper, bulbs light while rolling, the lever
pulls). Reels roll with a short strip scroll and land one by one (~170 ms apart); a button landing
sparkles, a miss puffs coral fluff with "+12" floating up, a crack rips the cell; banking pops
"+2 (button)". Your pet cheers every spin (PetBubble). Card picker = a small overlay panel inside
the side card (rows of MiniCards, tap = into the hopper). No hint text, no dropdowns, no '·'. Hopper
rows only for rarities you have pets of.

## Dev steps (DevDriver)

`open-plushie` (grants the find: the real unlock path, free button included), `wisps <n>`,
`buttons <slot>=<n> ...` (active pet), `hopper <rarity> <n>` (feeds n from the herd),
`land <slot>=button|blank|crack ...` (next spin lands these), `spin [n]`, `bank <slot>`,
`hold <slot>`, `nudge <slot>`.

## Flow: tests/flows/plushie.flow

from after_tutorial; parts open; `expect no-text "plushie machine"` on the workbench (hidden);
open-plushie (popup, active pet has 1 button, `expect fits`, shot opened); herd common/rare, wisps;
tab inventory, page 3; shot empty; hopper common 3, rare 1; spin with forced landings (button on
body, crack on eyes, blank...), shot mid_try (odds, held, marks); hold body, spin, bank; buy a nudge
+ a hold + the wild reel, nudge, shot shop; run the spins out, next!, shot next; swap keeper ‹ ›;
card pets picker, shot cards; the pet details show the buttons on the badges, shot badges;
`expect fits` after every screen. Also add a plushie page stop to fits.flow.
