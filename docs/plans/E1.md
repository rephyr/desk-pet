# E1 the old well dungeon (look A: the cross-section) + lanterns

The well line becomes one dungeon. The well trip stays (its top). The cellar and further down stop
being trip places and become bands of the dungeon. An army (card pets you add + herd reserves by
shelf) goes down floor by floor against a strength ~100 x 1.2^n. Cleared floors pay the darker
currency. Losses are the cost. Mockup: lanes/mockups design/mockups/screens/dungeon.html look A.

## Code

- `scripts/dungeon/dungeon.gd` (new, `class_name Dungeon`, static, pure rules, no state):
  `strength(f)`, `band_of(f)`, `floor_kind(f)` (rope / door / tiny / knock / stairs / guard),
  `pet_power(catalog, pet, knack_own)` (power stat with traits via Party.stat_of x rarity_x x
  finish_x x its own power knack), `herd_power(catalog, key)` (Herd.template), `army_power(...)`
  per floor kind (rope = front row only, tiny = rare+ only, else front + herd x herd_x, all x
  boost("power")), `word(ratio)`, `pay(f, sent)` (base x grow^f x min(sent, entrance)),
  `simulate(army, orders, deep, rng) -> run` : walks floors, per floor injures then loses a share
  (lose / ratio^2, capped), losses pick injured first then random, or by "who goes first" once
  earned (plain ones = herd first, the front row = cards first, anyone = random); a knock door
  rolls luck, a miss ends the run on the floor before (no pay for it); stops at the target, at
  "home when X% gone", or at a knock-back. Returns floors [{ f, lost_cards, lost_herd, pay }].
  Pay never looks at losses. Gear is never read.
- `scripts/game_state.gd` (kept small, the rest in Dungeon): `dungeon := Dungeon.fresh()`,
  `wisps := 0`, signal `dungeon_changed`.
  `dungeon_open()`, `army()` (front row / reserves / herd picks / sent / power),
  `set_army_card(uid, on)`, `army_best()`, `set_army_herd(rarity, n)` (clamped to resting herd and
  the entrance), `set_order(key, step)`, `send_army()` (snapshot, simulate, run saved, cards and
  herd counts busy), `dungeon_floor_now()`, `_finish_dungeon_run()` (lost cards via
  collection.remove, lost herd via new `Collection.lose_plain(key, n)`, both add stars; wisps;
  deepest; firsts once; "last time"; pet line), `_earned` gets `floor`.
  Busy pets: `away()` includes the army's cards, `_herd_used` its herd counts (so they're off
  errands, workers and parties). `location_open` is false for band places; `_hear_rumours` skips
  retired ones; `auto_places` never offers band places.
- `scripts/idle/automation.gd` + GameState automation tick: task `army` re-sends the same army
  with the same orders whenever it's home (while the game runs, plus once on load).
- `scripts/pets/collection.gd`: `lose_plain(key, n)` (bulk herd loss, one star each).
- `scripts/dev/dev_driver.gd`: steps below.

cards: [uids], herd: { rarity: n }, run: null | { at, per, floors, cards, herd, sent },

Migration: fresh dungeon; `location:cellar` unlocked -> bands + cellar, `location:below` -> +
below (bands already reached; the unlocks stay); waiting rumours drop cellar/below; your pet's
and workers' parties at cellar/below move to the well; runs already there finish as normal.

## Dev steps + flow

Steps: `dungeon` (the rope find: opens it), `army best`, `army-herd <rarity> <n>`,
`orders <floor> <home%> [first]`, `down`, `down-done` (the run ends now), `deep <n>`, `wisps <n>`.

(shot the popup), adventures page 2 (shot empty), army best, army-herd, orders 12 30 (shot,
expect fits), down, wait (shot mid-run), down-done (shot last time + lit landings), deep 24 +
scroll (shot stairs + guard), expect fits on each.
