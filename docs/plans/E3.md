# E3 the sewing room (off well floor 20)

From docs/picks.md (Brainstorm 3 "E3", Look picks round 3 "well additions") and the mockup
lanes/mockups2 design/mockups/screens/well-additions.html (the sewing room part; column = look A).
Builds on this branch's E1 dungeon (army maths), F1 plushie machine (buttons, `find:plushie_machine`)
and C3 sorting rule.

## What it is

- **The door:** once the tiny key is found (floor 20's first clear, `finds.little_key`), a small
  pink arched door with a coral knob is drawn in the right wall of floor 20 on the well column.
  Nothing is drawn before that. Tapping it slides the column sideways (tween, ~0.45 s) to the rooms
  pane; the column header turns into `‹ the sewing room` (‹ slides back).
- **Rooms:** 9 fixed rooms, each a single fight against a strength (E1 maths:
  `Dungeon.strength` at the room's floor-equivalent, x `room_x`) AND a chalk lock. Only the rooms
  cleared + the next one show (dots for those only). Cleared rooms can be entered again (wisps,
  no first-time reward).
- **Chalk lock:** 3-5 marks on a chalkboard: part pictures for named knack parts (bunny ears,
  halo, horns, crown, headphones, sparkle eyes...), trait icons, finish swatches, rarity circles
  (in the tier colour). Dashed chalk while unmatched; solid fill when any front-row pet (the army's
  best 20 cards, not your pet with the flag) matches. Matching front-row cards get a chalk tick on
  the FrontRow. Tapping a dashed mark: your pet says where it comes from (`GameState.sew_hint`,
  like `bit_hint`). `in we go!` only works when every mark is solid and the army has pets.
- **A room run:** the same army as the well (its cards + herd, entrance, "who goes first"), one
  fight, `seconds` long (party stands at the door on the column meanwhile). Losses as a well floor
  (stars, never mentioned); too weak (< stuck) = no pay, back home. Clears pay wisps like a well
  floor at the room's floor-equivalent (x `pay_x`).
- **Firsts:** room 1 teaches keep lines (1 line), rooms 4 and 7 add a line each (3 total). The
  last room (9) grants `find:plushie_machine` (the existing plushie unlock: machine opens + one
  free button on your active pet).
- **Rolled rooms:** after room 9, the next room is rolled (deterministic from its number: a picture
  and name from a list, strength keeps growing), one mark is always a **button lock** (a pet with
  N buttons, N grows) plus rolled marks from a pool. Farm forever, same wisps.
- **Keep lines** (on the sorting card, hidden until earned): `keep ‹zoomy ones›`,
  `keep ‹halos›`, `keep ‹nothing›` by default. Options: every trait + the knack parts from the room
  marks the book has seen. A new pet (box opening) matching a line stays a card (not sorted away,
  not folded, the stall never takes it); each line keeps its last `cap` (50) matches, the oldest
  past that becomes plain again. A small `n/50` count at the line's end. Changing a line's pick
  lets its old keeps go. Lines work whether the rule is on or off.

## Data: data/sewing.json (new, all numbers placeholders)

```
{ "_note", "door_floor": 20, "seconds": 60, "room_x": 1.0, "pay_x": 1.0,
  "keep": { "cap": 50 },
  "rooms": [ { "id": "tin", "name": "the button tin", "floor": 21,
               "marks": ["part:body:bunny", "tier:rare", "finish:shiny"], "first": { "keep_lines": 1 } },
             ... pin cushion 23, thread maze 25, ribbon drawer 27 (+1 line), thimble tower 29,
             pattern book 31, needle case 33 (+1 line), the big scissors 35,
             the sewing basket 38 (horns...; "first": { "find": "plushie_machine" }) ],
  "rolled": { "floor_start": 40, "floor_step": 2, "rooms": [{ "id", "name" } x ~8],
              "marks": { "start": 2, "every": 5, "max": 5 },
              "buttons": { "start": 1, "every": 3, "max": 25 }, "pool": ["part:accessory:halo", "trait:brave", ...] },
  "marks": { "part:body:bunny": { "doodle": "chalk_ears", "say": "bunny ears" }, ...traits, finishes },
  "hints": { "part": "...{what}...{tier}...{box}", "trait", "finish", "tier", "buttons" } }
```

Marks and keep-line picks are strings: `part:<slot>:<id>`, `trait:<id>`, `finish:<id>` (exact),
`tier:<id>` (exact, like the mockup), `buttons:<n>` (a pet with at least n buttons).

Other data: unlocks.json (unlock `sewing`: earn find little_key, opens feature:sewing, quiet,
announce; unlock `keep_lines`: earn `{ "sewing": 1, "open": "feature:sorting" }`, popup, go
collection; new earn key `sewing` = rooms cleared; plushie_machine `given_by` -> the last room),
voice.json (sewing_* lines), catalog.gd (`catalog.sewing`).

## Code

- **New `scripts/dungeon/sewing.gd` (Sewing, pure):** fresh/clean, `room(catalog, i)` (fixed or
  rolled), `shown(state)`, `strength`, `pay`, `mark_matches(catalog, mark, pet)`,
  `marks_on(catalog, room, front)`, `ticks(...)`, `keep_lines(catalog, cleared)`, `keep_options`,
  `keep_matches`. State `{ cleared }` (rooms cleared in order, fixed then rolled).
- **dungeon.gd:** the per-floor fight moves into a shared `_fight`; new `simulate_room(catalog,
  army, strength, pay, orders, rng)` returns the usual run shape (one entry). `run_seconds` reads a
  run's own `seconds`; `run_floor` returns the door floor for a room run.
- **game_state.gd:** `sewing` state; `sewing_open`, `sew_room`, `sew_front`, `sew_marks`,
  `send_to_room(i)` (run in `dungeon.run` with `room: i`, so army pets stay busy through `_out()`),
  `_finish_dungeon_run` branches to `_finish_room_run` (losses, wisps, cleared++, firsts,
  `dungeon.last.room`, news); `sew_hint(mark)`; keep lines: `set_keep_line(i, pick)`,
  `keep_line_options()`, sorter asks keep lines first (`_sorter` also valid when only lines are set),
  `collection.kept` rebuilt from `homes.kept`; `_earned` knows `sewing`. Safety on load: deep >= 20
  without the key gets it.
- **collection.gd:** `kept` (uid -> true) counts in `always_card`.
- **new_homes.gd:** `rule.lines` + `kept` in fresh/clean.
- **UI:** new `SewingRoom` (scripts/ui/sewing_room.gd: `‹ name ›`, dots, the arched chamber with
  the room picture (SVG line drawings from the mockup, one per room), the chalkboard of
  `ChalkMark`s, footer: feeling word or coral pennant + `in we go!` / `on the way…`); new
  `ChalkMark` (scripts/ui/chalk_mark.gd, dashed vs solid chalk doodles, tier ones in tier colour);
  DungeonView (a clipped pan holding the well scroll + SewingRoom, header swap, FrontRow ticks in
  rooms view, last-time card shows the room name); WellColumn (door + a `SewDoor` button child);
  FrontRow (optional ticks); SortingCard (keep lines under the keeps, hidden until earned);
  UiTheme (chalk doodles: parts, traits, finish swatches, tier circle, buttons).
- **tools/balance.gd:** a rooms table (which armies clear which room).

## Flow: tests/flows/sewing.flow (+ a stop in fits.flow)

from rich, pets, herd, unlocks (well, sorting); `dungeon`; `deep 20`; dungeon page: no door ->
`find little_key` -> shot `door`; `click SewDoor#1` -> expect "the sewing room", "the button tin";
shot `locked`; `mark 1` (the hint); `card body=bunny rarity=rare finish=shiny` etc.; `army best` ->
shot `ready` (solid marks, ticks); `in`; `down-done`; expect "last time"; keep lines popup -> shot
`keep_popup`; pets tab, `keep 1 trait:zoomy` -> shot `keep_lines`; `sewn 8`, `room 9`, dress the
army, `in`, `down-done` -> plushie popup -> shot `plushie`; rooms pane -> rolled room with a button
lock -> shot `rolled`. `expect fits` on every screen.

Dev steps: `door`, `room <n>`, `sewn <n>` (clears rooms with their real firsts), `in`, `mark <n>`,
`card k=v... [n]` (new card pets with those parts/traits/finish/rarity), `keep <line> <pick|none>`.
