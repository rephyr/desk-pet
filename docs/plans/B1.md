## Data: gated looks in data/parts.json

A part gets `"from": "<box id>"`: it only rolls from that box tier or higher (by box order).
Picked from existing parts (no new art):

- **sunset box**: fox (body, epic), stars (pattern, epic), gold (palette, legendary)
- **midnight box**: dragon (body, legendary), halo (accessory, epic), midnight (palette, rare)

Midnight looks stop dropping until next door exists (pets that have them keep them). A roll that
lands on a gap steps down like today (legendary body from a sunny box -> the best body below).

## Code

- **Catalog**: `box_rank(id)` (order among shop boxes), `parts_in(slot, tier, box_id)` (parts_of_tier
  minus gated ones), `shop_boxes()` (not hidden). `parts_of_tier` stays as is (book, grafting, tests).
- **PetRoller**: `_signature_slot`, `_best_rank_in`, `_pick_part` use `parts_in(.., box_id)`. New
  `roll_box(box_id, force_tier) -> Array[Pet]`: rolls `pets` [min, max] pets (the forced tier is
  for the first one only).
- **Rewards.roll_part**: uses `parts_in` with the place's box, so backyard trips never bring sunset
  looks. adventures.json: cellar and below `"box": "lucky"` -> `"sunset"` (the rest unchanged).
- **GameState**:
  - `open_boxes(box_id, count, ...)` rolls `roll_box` per box, still takes `count` boxes off the
    pile; returns all pets (best first within each box).
  - `shop_boxes()` = shop boxes whose page is open (+ all of them with dev `tiers all`).
  - `boxes_bought` {id: n}: counted in buy_boxes. A tier shows the gold "new!" tag while it's in
    the shop and `boxes_bought` has none of it (never on the sunny box).
  - `next_pet_box()` and the piggy bank buying only pick tiers in the shop and switched on.
  - `_workers_open(count)` counts BOXES, not pets (today it adds `pulled.size()`, which would be
    2-3x too many with sunset boxes).
  - `auto_open_pack()` opens one box, returns its best pet (the pack job shows that one), logs
    every pet, pins good ones.
  - `debug_all_tiers` (debug builds, not saved) for the fits check with 3 tiers.
- **Save v22 -> v23** (merge step renumbers): `bag.lucky` -> `bag.sunset` 1:1 (converted, not
  refunded: the sunset box is the lucky box's successor), `saved_boxes` "lucky" -> "sunset",
  saved runs' loot "box:lucky" -> "box:sunset"; new field `boxes_bought` (old saves: 1 for every
  kind already on the pile, so migrated boxes get no "new!" tag). Pets keep `box: "lucky"`
  (just a string).

## UI: scripts/ui/boxes_tab.gd (look C)

Layout changes from "counter on top, table + side below" to the mockup's two columns:

```
+-- left (expands) -----------------------------------------+ +-- side 232 ---------+
| (o) [pack] sunset box  new!      [fox][stars][gold]  - 1 + | | [pet on cushion]    |
|  stamp      (coin 400) (1)(10)(50)   inside: o o o  [buy 1]| | lilac blob       [x]|
| (o) [pack] sunny box                                 - 1 + | | opening boxes       |
|             (coin 50)  (1)(10)(50)   inside: o     [buy 1] | | [on] (h) sunny box  |
| +-- your stash ----------------------------------------+   | | [on] (f) sunset box |
| |     [pile]            [pile]                         |   | | ---- piggy bank ----|
| |    sunny box        sunset box                       |   | | buy more ... [x]    |
| |  open [1][10][all]  open [1][10][all]                |   | | keep at least - 50 +|
| |======================================================|   | +---------------------+
+-----------------------------------------------------------+
```

- Counter row per shop tier, newest on top (like the mockup, the tier just earned is the first
  thing you see): **stamp** (dashed circle, map page doodle, tilted, tooltip = page name),
  pack art (odds on hover, as today), name + gold **new!** tag, **new looks** stickers (tiny
  portraits of a plain pet wearing each gated part, name on hover), price chip + 1/10/50 chips,
  **inside** silhouettes (PetPortrait silhouettes: 1 for sunny, 3 for sunset with the 3rd fainter
  = 2-3), stepper + buy.
- Stash: one smaller pile per shop tier (packs ~46 px so 3 piles fit), "open" + 1 / 10 / all.
- Side job card: pet + master switch (today's), then a toggle per tier (stamp doodle + name,
  on = pet opens it, off = save for me; same `saved_boxes`), then the piggy bank part as today.
- A tier arriving: when the tab refreshes with a new tier, its row pops in with a sparkle once and
  your pet says a line (boxes.json `arrives` per box, e.g. "new boxes! they came all the way from
  beyond the fence."). No explanation text.
- Buttons get node names (`buy_sunset`, `open_sunset_1/10/all`, `amount_sunset_10`) for flows.
- **Opening one box with 2-3 pets**: the pack ritual plays for the best pet; the result card
  gets an "also inside" row of small portraits for the others. Open 10 / all: BoxReveal grid as
  today, but it tracks boxes and pets apart ("open 10 more" means boxes; title "opening 10
  boxes...", "27 pets!").
- Crayon: new doodles `fence` and `moon` for the stamps.

## Tests (tests/test_core.gd)

- odds match for sunset and midnight (existing `_test_odds_match_box`).
- sunny never rolls glitch/prismatic, sunset never prismatic (2000 rolls each).
- gated looks: sunny rolls (forced to every rarity) never have a sunset/midnight part; sunset
  rolls never have a midnight part and can have fox; Rewards.roll_part with a sunny place never
  gives a gated part.
- roll_box: sunny gives 1 pet, sunset 2-3.
- shop tiers: sunny only at start, + sunset with page:beyond, midnight never (no page).
- migration: a v22 save with bag { lucky: 3 } and saved_boxes [lucky] loads as sunset 3.
- workers open N boxes, not N pets.
- tools/balance.gd: a line per tier (coins per pet, average rarity rank, chance of a new look).
