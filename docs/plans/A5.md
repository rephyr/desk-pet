# A5 the sunset globe: build plan

Look A from lanes/mockups globes.html: the sunny globe (smaller, left, workers on its lever) and the
big sunset globe (right) stand side by side on one stage; a "sunset fixes" list replaces "next up"
while the newest globe still has repairs. Picks: docs/picks.md A5 + "Look picks, round 2".

## Rules

- **Arrival:** a find in **the far fields**, event `fields_sunset_globe` (`after_machine: drops`,
  `after: tiny_machine`, `auto: true`), so it's the next fields trip after the tiny machine and
  never lands before its branch can grow off the hatch. Find id `sunset_globe`.
- **Hand globe** = the newest globe home whose `works` repair is fixed (sunset: "shoo out the
  nest"). Before that you keep pulling the sunny globe; the broken sunset globe just stands there.
  **Behind globe** = the one before the hand globe (or the hand globe when it's the only one).
  Your pull uses the hand globe. Your pet's crank, workers' capsules and errands' capsule value
  (`job_boost`) use the behind globe.
- **Per-globe numbers.** Each node gets `globe` (default sunny). Own effects count only on their
  globe: `chutes`, `lights`, `glass` (shiny works on this globe), `hatch`. Shared effects count on
  their globe and every newer one: `coins_x`, `double`, `triple`, `shiny`, `shiny_x`, `fever_s`,
  `drops`. A globe's coin value = base x shared coins_x x its `step` (sunset x4, midnight x4). So
  the sunset globe starts with 1 chute, no lights and no shiny until amber glass, but its capsules
  are worth x4 and gold-plated coins etc. still count.
- **The hatch** (sunset's "the rusted hatch"): box and pet-box prizes on that globe become its
  box tier (`sunset`), and its toy set joins the toy roll. Before its hatch a globe drops what the
  globe before it drops (sunny boxes, backyard toys).
- **Sunset lever before the pulley:** droops and springs back slowly (heavy), still pullable. After
  the pulley it's normal.
- **Bits:** corks + amber glass (orchard), pulleys (old well), copper wire (far fields), only once
  the sunset globe is home (finish reward `after: sunset_globe`). Bits pills show the newest
  globe's bits.
- **Midnight globe:** data only (globe entry, find `porch_machine`, box `midnight`), no nodes. The
  code handles any number of globes; tests use an injected catalog with midnight nodes.
- One lights counter and fever, on the hand globe.

## Code

- `scripts/machine/machine.gd`: `globes`, `globe(catalog, id)`, `home(state)`, `hand(state, catalog)`,
  `behind(...)`, `newest(...)`, `bits_of(catalog, globe)`, `bit_info`; every per-globe function
  (`coin_value`, `chutes`, `many_capsules`, `lights_on`, `shiny_chance`, `shiny_pay`,
  `balls_from_chute`, `roll`, `odds`, `loot`, `fever_*`) takes `globe := ""` ("" = hand), so old
  calls keep working. `look()` hides nodes whose globe isn't home. `box_of(state, catalog, globe)`,
  `toy_sets(...)`. `BITS` goes (data now), `BRANCHES` + "sunset".
- `scripts/game_state.gd`: `machine.globes` + `machine.greeted`; grant(find) brings globes home
  (`globe_arrived` signal); `pull_lever`/`_capsule` on the hand globe (box/pet box via `box_of`);
  `_pet_capsule` + `job_boost` on the behind globe; `greet_globe(id)`; `bit_hint` / plurals from
  data. `AdventureRunner.resolve(..., found)` so `_finish_treat` skips rewards whose `after` isn't
  found; grant() also skips bits of a globe not home (safety net).
- `scripts/machine/toys.gd`: `roll(..., sets)` limited to the globe's sets.
- `scripts/ui/machine_tab.gd`: `MachineStage` gets `globe` + `hand` (skin colours from the globe,
  broken sunset bits: leaves/rust arc (nest), 3 holes with a capsule dripping out (holes), drooped
  heavy lever (sag), cloudy glass (amber; after: warm glow), rusted tilted hatch (hatch); sparkle via
  `fixed()` as now). Non-hand stage: no input, no counter; the workers-only one loops its lever with
  the first machine worker hanging on it while workers crank. Stage panel = one stage (as now) or
  two side by side with a tilted sign above each and a stat under ("14 workers / 2.4k coins a
  capsule", "9.6k coins a capsule / 1 chute"). Arrival: the sunset stage slides in with a dust puff
  and your pet says `arrives` once (news dot on the machine tab until seen). `FixList` (236 px, the
  side column): header with globe icon, a row per repair of the newest globe (disc icon, name, needs
  line with short bits in pink, or a tick), the picked row opens (says, gain, fix it / not yet).
  Shows while the newest globe has unfixed repairs, else "next up" as now. Bits pills = newest globe.
  OddsCard follows the hand stage.
- `scripts/ui/machine_tree_view.gd`: frames the newest globe's `view`; older nodes drawn faded;
  tilted "sunny globe" / "sunset globe" signs pan between views (tween). MachineMini draws the
  node's globe. Branch colour "sunset".
- `scripts/ui/ui_theme.gd`: icons bit_cork, bit_pulley, bit_wire, bit_amber, nest, cork, pulley,
  amber, hatch (from the mockup SVGs); a colour helper for role-or-hex.
- `scripts/ui/map_view.gd`, `adventures_tab.gd`, `postcard.gd`: bits from data, places with two
  bits (orchard) show both, only once their `after` is found.
- `scripts/ui/toys_view.gd`: sunset set hidden until its hatch is open or you own one of its toys.

## Save

v23 -> **v24**: `machine.globes` (missing -> ["sunny"]), `machine.greeted` (missing -> copy of
globes). Unknown globe ids dropped on load; a save that has a globe's find but not the globe gets
it (idempotent sync on load).

## Flow `globes.flow`

from new, dev `fix` the whole sunny tree + bits, `find intel_fence`, `find tiny_machine`, tab
machine, shot before -> `find sunset_globe` -> shot arrival (both globes, fix list, sunset pills)
-> `expect fits` -> click a fix row (name:fix_cork) shot -> `bits cork 5` ... -> fix nest, shot
(hand moved, drooped lever), `pull 1` shot -> teach + spots + workers on the machine, shot (worker
on the sunny lever) -> fix cork, pulley, amber, hatch with shots (each broken bit gone) -> pull
with `next-prize box` (sunset box) -> upgrades page shot (sunset view), click "sunny globe" sign
shot, `expect fits` on each page. Re-run machine, machine_odds, fits, pet_box, workers, automation,
box_tiers.

## Tests (tests/test_core.gd `_test_globes`)

Per-globe coin value / chutes / lights / shiny (own vs shared, step); hand/behind before arrival,
arrived broken, after nest; nodes hidden until home; `box_of` switches at the hatch; sunset toys
only after the hatch; finish treat has no corks without the find and has them with it; every node's
bits exist in `bits` and every sunset bit has a place; pills = newest globe's bits; job_boost and
pet capsule use the behind globe; injected midnight catalog (3 globes: hand midnight, behind
sunset); save v23 -> v24 migration. tools/balance.gd: a "globes" table (coins per pull, hand vs
behind, at each sunset fix from a maxed sunny machine) to check fixing the nest never makes your
pull worse; tune `step` in data if it does.
